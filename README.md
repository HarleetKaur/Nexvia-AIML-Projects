# Nexvia Technologies — AI/ML Internship Projects

This repository contains both assigned capstone projects.

## Project 2 (AIML-03) — Large-Scale Personalized Recommendation Engine

Location: `Project-2/`

Two-stage recommendation system with two-tower retrieval, FAISS,
DCN and Wide & Deep ranking, Redis caching, FastAPI, Triton inference,
and Airflow retraining configuration.

FastAPI-to-Triton inference has been verified with both rankers.
The A/B reporting implementation is available, but real-user
experimentation has not been demonstrated. Scheduled Airflow
execution has not been independently verified.

Original repository:
https://github.com/HarleetKaur/recsys-engine
